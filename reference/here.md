# Here

A utility to make sure the system files of the package and other files
are always found, regardless if they are in an example or vignette
context.

## Details

See `here::`[`here`](https://here.r-lib.org/reference/here.html) for
details.

## Examples

``` r
dir(here("inst", "examples"))
#> [1] "ZA5913.rds"         "ZA6863.rds"         "ZA7576.rds"        
#> [4] "afrob_vignette.rda" "iris1.sav"         
```
