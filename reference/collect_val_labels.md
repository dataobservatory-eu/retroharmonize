# Collect labels from metadata file

Collect labels from metadata file

## Usage

``` r
collect_val_labels(metadata)

collect_na_labels(metadata)
```

## Arguments

- metadata:

  A metadata data frame created by
  [`metadata_create`](https://ropengov.github.io/retroharmonize/reference/metadata_create.md).

## Value

The unique valid labels or the user-defined missing labels found in all
the files analyzed in `metadata`.

Other harmonization functions:
[`crosswalk_surveys()`](https://ropengov.github.io/retroharmonize/reference/crosswalk_surveys.md),
